## 🔐 SECURITY ARCHITECTURE

### RBAC Roles
```
admin        → All departments
finance      → Finance only
hr           → HR only
engineering  → Engineering only
```

### Security Guarantee
```
REQUEST
  ↓
Authentication
  ↓
🔐 RBAC Authorization Check
  ↓
Retrieval (if authorized)
  ↓
🔐 RBAC Filtering
  ↓
Response (no unauthorized data)
```

**Key Point:** Unauthorized documents are never even retrieved!

### Main Endpoints

### Example Query
```bash

  -H "Content-Type: application/json" \
  -d '{

    "user_role": "admin",
    "top_k": 5
  }'
```

## 💻 ADDING YOUR OWN DATA

### Add Event Logs
Create file: `data/logs/myevents.json`
```json
[
  {
    "timestamp": "2026-03-15T10:00:00Z",

    "details": "Q1 summary"
  }
]
```

### Update RBAC Roles
Edit: `data/policies/rbac.json`
```json
{
  "mynewrole": {
    "accessible_departments": ["finance"],
    "can_access_all": false,
    "sensitive_operations": false
  }
}
```

