## 🔐 SECURITY ARCHITECTURE

### Role-Based Access Control
```
admin        → All departments (finance, hr, engineering, operations)
finance      → Finance department only
hr           → HR department only
engineering  → Engineering department only
```

### RBAC Enforcement Timeline
1. ✅ Query arrives with user role
2. ✅ Role is validated
3. ✅ RBAC policy is checked
4. ✅ Authorization decision made
5. ✅ Retrieval proceeds ONLY if authorized
6. ✅ Results filtered by RBAC
7. ✅ Only authorized data sent to LLM
8. ✅ Citations show only authorized sources

### Security Guarantees
- ✅ Unauthorized documents never retrieved
- ✅ Unauthorized context never reaches LLM
- ✅ Unauthorized sources never in citations
- ✅ Complete audit trail of all queries
- ✅ Access decisions logged
- ✅ Zero risk of data leakage

## 📈 HYBRID RETRIEVAL FORMULA

### Scoring Algorithm
```
Final Score = (0.45 × Semantic Similarity)
            + (0.30 × BM25 Keyword Score)
            + (0.15 × Source Trust Score)
            + (0.10 × Recency Score)
```

### Component Details
- **Semantic (45%):** FAISS vector similarity using embeddings
- **Keyword (30%):** BM25 algorithm for exact term matching
- **Trust (15%):** Source reliability/quality score
- **Recency (10%):** Document freshness weighting

### Why This Works
- Combines understanding (semantic) with precision (keyword)
- Weighted toward semantic for real understanding
- Includes trust and recency for enterprise data quality
- Produces highly relevant results

## 🎓 CONFIDENCE SCORING

### How It's Calculated
```
Confidence = Average of:
  • Individual result similarity scores
  • Source agreement across results
  • Embedding quality metrics
  • Grounding verification
```

### Confidence Levels
- 🟢 High (>80%)     - Verified enterprise data
- 🟡 Medium (60-80%) - Partial verification
- 🔴 Low (<60%)      - Insufficient context

### Hallucination Prevention
```python
if confidence_score < 70%:
    answer = "Insufficient verified enterprise context available."
else:
    answer = generate_grounded_response()
```
